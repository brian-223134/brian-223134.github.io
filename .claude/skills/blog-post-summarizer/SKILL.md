# Blog Post Summarizer

## 목적
`_posts/` 디렉토리의 포스트를 검색·파싱하여 사용자가 원하는 형태로 요약한다.

## 워크플로우

### Step 1 — 요청 파악
사용자 요청을 아래 세 가지 유형으로 분류한다:

| 유형 | 예시 | 동작 |
|------|------|------|
| 특정 포스트 요약 | "nlp-03 요약해줘" | 해당 파일 1개 파싱 → 요약 |
| 카테고리 탐색 | "NLP 포스트 목록 보여줘" | 해당 카테고리 전체 파일 목록 반환 |
| 키워드 검색 | "attention 관련 포스트 찾아줘" | 전체 포스트 본문에서 키워드 탐색 |

### Step 2 — 파일 탐색

```
_posts/
├── YYYY-MM-DD-카테고리-번호.md  ← 파일명 패턴으로 카테고리 필터 가능
└── ...
```

- 카테고리 필터: 파일명의 날짜 뒤 부분으로 1차 필터링
- 추가 확인: front matter의 `categories`, `tags` 필드
- 전체 목록이 필요하면 `_data/navigation.yml`로 카테고리 구조 먼저 파악

### Step 3 — 파싱 규칙
포스트 파일을 읽을 때 아래 순서로 파싱한다:

1. **front matter** (`---` 블록) — title, excerpt, categories, tags, date 추출
2. **본문 헤딩** (`##`, `###`) — 섹션 구조 파악
3. **본문 내용** — 요약 대상

### Step 4 — 요약 출력 형식

**단일 포스트 요약**

```
## [카테고리] 제목
- 날짜: YYYY-MM-DD
- 태그: tag1, tag2
- 파일: _posts/파일명.md

### 요약
(핵심 내용 3~5줄 — 논문 리뷰라면 방법론·결과 중심)

### 섹션 구성
1. 배경
2. 방법론
...
```

**목록 반환 (카테고리 탐색: 예시 상황)**

```
## NLP 포스트 목록 (총 N개)

| 번호 | 제목 | 날짜 | 태그 |
|------|------|------|------|
| 01 | ... | 2026-01-10 | BERT, NLP |
| 02 | ... | 2026-02-03 | GPT, LLM |
```

## 주의사항
- 포스트가 존재하지 않으면 "해당 조건의 포스트를 찾을 수 없습니다"라고 명시
- 요약은 본문을 충실히 반영할 것 — 임의로 내용을 추가하지 말 것
- 논문 리뷰 포스트(NLP 카테고리)는 방법론과 실험 결과 위주로 요약
- 키워드 검색 시 front matter와 본문 모두 탐색할 것
